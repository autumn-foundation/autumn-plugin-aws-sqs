# Acceptance criteria: evidence

Issue: autumn-foundation/autumn-plugin-aws-sqs#1. Branch head: see the PR.

| AC | Criterion | Evidence |
|---|---|---|
| AC1 | `AwsSqsPlugin` implements `Plugin`. One call installs it. | `src/plugin.rs` (`impl Plugin for AwsSqsPlugin`, name `autumn-plugin-aws-sqs`). Tests: `runtime::plugin_installs_with_one_call` (TestApp, `/actuator/health` shows `aws_sqs` UP), `runtime::plugin_name_is_stable`. Example app `examples/app.rs` boots with `.plugin(AwsSqsPlugin::new()...)`. |
| AC2 | `SqsJobClient` sends a `#[job]` with `enqueue`, `enqueue_in`, `enqueue_at`. A worker runs the same handler. | `src/jobs.rs`. Tests: `jobs::enqueue_runs_same_handler_and_deletes`, `jobs::enqueue_writes_job_envelope_and_attributes`, `jobs::enqueue_at_past_runs_now`, `failures::enqueue_at_future_waits`, `localstack::job_end_to_end_retry_dead_letter_and_delay`. | AC3 | The worker obeys `max_attempts`, `backoff_ms`, `queue`, `version`. | Tests: `jobs::failure_retries_with_backoff_then_succeeds`, `failures::retry_backoff_doubles` (1 s then 2 s), `jobs::exhausted_job_goes_to_dead_letter_queue` (attempts = 2), `jobs::queue_attribute_routes_to_alias_url`, `jobs::versioned_payload_is_wrapped_and_decoded`. | AC4 | Delay: 900 s or less uses `DelaySeconds`. Longer hops. Verus: `split_delay`. |
| AC5 | Retry with backoff. | AC6 | A heartbeat extends visibility for long handlers. | Test: `jobs::heartbeat_keeps_long_handler_invisible` (35 s handler, 10 s visibility, one run). 12 h budget: Verus `clamp_visibility`, `memory::visibility_change_respects_twelve_hour_budget`. |
| AC7 | Consumers run typed handlers. SNS unwrap. | `src/consumer.rs`. Tests: `runtime::consumer_runs_typed_handler_and_acks`, `runtime::consumer_bad_json_is_rejected_to_dead_letter`, `runtime::consumer_retry_error_uses_consumer_attempts`, `runtime::consumer_autumn_error_converts_to_retry`, `runtime::sns_envelope_unwraps`, `failures::fifo_group_runs_in_order_even_after_a_retry`, `failures::fifo_held_messages_keep_their_attempts`, `localstack::fifo_consumer_keeps_group_order_on_real_sqs`. |
| AC8 | Producer: one, JSON, batch (10 and 1 MiB), per-entry results, FIFO IDs. | `src/producer.rs`. | AC9 | Workers only when `runs_workers()`. | AC10 | Health indicator. Metrics with counters and queue depth. | `src/health.rs`, `src/metrics.rs`.
